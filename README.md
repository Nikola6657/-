# 代码查错

一个按你的原有写法修复代码的 Codex Skill。显示名称为 **查错**，调用标识为 **`$cha-cuo`**。

**只改错误的部分；没错的函数名、变量名和代码结构保持原样。最后给出带修改注释的完整代码。**

## 按你的写法修改

“按照原思路”不仅是实现相同功能，还要保留你的具体写法：

- 你写了判断函数，就在你的判断函数中修正，不换成另一个函数或库调用。
- 保留无误的函数名、变量名、参数、返回接口、数据结构和函数划分。
- 保留无误的判断方式、循环形式、语句顺序、格式和原注释。
- 不因为命名不规范、写法不简洁或存在优化空间，就重构或重写代码。
- 只有名称、接口或结构本身导致错误时，才修改它及必要的关联引用，并说明原因。

每一处改动都应能对应一个明确的问题或修复它所必需的关联修改。

## 你会得到什么

1. **错误位置**：文件名和原行号；粘贴的代码从第一行开始计数，并引用关键原语句。
2. **出错原因**：顺着入口、判断、循环和变量变化，解释哪里最早偏离预期，区分根因与连带报错。
3. **修改说明**：解释具体改哪一处、为什么必须改，避免无关调整。
4. **验证情况**：给出触发问题的最小用例与预期结果；区分实际运行和静态推演。
5. **完整修正版代码**：作为答复的最后部分，在修改位置添加合法的“修改：”注释，不使用省略号或“其余不变”。多个文件分别完整给出。

只提供片段时，完整返回该片段的修正版，不编造未提供的源码。没有明确错误时会直接说明，并返回原代码；信息不足的疑点会标为“待确认”。JSON 等不支持注释的格式，会在代码块前说明修改位置，保持代码合法。

## 安装

下载本仓库 ZIP 并解压，或克隆本仓库。将其中的 `skills/cha-cuo` 整个文件夹复制到个人技能目录 `~/.codex/skills/` 下。

安装后的结构应为：

```text
~/.codex/skills/cha-cuo/
├── SKILL.md
└── agents/
    └── openai.yaml
```

Windows 中，`~` 表示你的用户主目录。技能列表未刷新时，可重新打开 Codex 后查看“查错”。无需额外安装依赖或配置 API 密钥。

## 使用

发送代码并调用技能，例如：

````text
$cha-cuo
这个函数应该判断 n 是否为偶数，请按我的写法查错，只改出错的部分。

```python
def panduan(n):
    if n % 2 == 0:
        return False
    else:
        return True
```
````

它会说明两个分支的返回值与预期相反：例如输入 `2`，原代码返回 `False`，但应返回 `True`。最后的完整修正版会保留你的函数名、参数和 `if/else` 写法：

```python
def panduan(n):
    if n % 2 == 0:
        return True  # 修改：偶数应返回 True
    else:
        return False  # 修改：奇数应返回 False
```

可用 `panduan(2) == True`、`panduan(3) == False`、`panduan(0) == True` 验证。以上示例以整数输入为前提。

## 范围与隐私

本仓库只有技能说明、界面配置和 README，没有执行脚本、账号配置、API 密钥或遥测代码。默认提供分析与完整修正版；只有用户要求直接修复文件时才编辑源码。

技能不会把风格评价或整库审计当成查错。它也不应为了验证而执行会删除数据、发送消息、付费或写入外部系统的代码。

使用时，代码仍由你所使用的 Codex 环境及其模型处理；本技能不提供额外的数据隔离。提交代码前请移除密钥、密码和不应分享的业务数据。
